# LARP Tycoon

Редактируемая карта Roblox для многопользовательского тайкуна от LARP Studio. Восемь участков размером 104 × 104 стада выходят на две параллельные улицы. В центре находятся площадь, фонтан, зона появления и объёмная надпись **LARP STUDIO**. У каждого участка свой цвет, одинаковая площадь застройки и свободный вход с тротуара.

## Открыть готовую карту

1. Скачайте `LarpTycoon.rbxlx` и откройте файл в Roblox Studio через **File → Open from File**.
2. В **Explorer** найдите `Workspace → LarpTycoonMap` и `ServerStorage → LarpTycoonAssets`. Через **Play** можно осмотреть начальную площадку. Настройки места, в том числе лимит игроков, задаются при публикации проекта в Roblox.
3. Сохраните копию места перед настройкой карты или подключением серверной логики.

В готовом файле уже есть объекты карты, точка появления, освещение и шаблоны. Генератор не нужен при запуске игры или сервера.

## Сгенерировать карту через Command Bar

1. Откройте пустое место или рабочую копию своего проекта в Roblox Studio. Если используете шаблон Baseplate, удалите его исходную площадку и исходные `SpawnLocation`, чтобы они не пересекались с картой и игроки появлялись на площади.
2. Оставайтесь в режиме редактирования. Откройте **View → Explorer**, **Output** и **Command Bar**.
3. Скопируйте весь текст `MapGenerator.luau`, вставьте его в **Command Bar** и выполните. В многострочном режиме воспользуйтесь кнопкой запуска или **Ctrl+Enter** на Windows (**⌘+Enter** на macOS).
4. Проверьте строку `LARP Tycoon | 8 plots, 4 floors and 64 upgrade slots per plot` в **Output**, затем сохраните место.

Повторный запуск заменяет ранее сгенерированные `LarpTycoonMap`, `LarpTycoonAssets` и эффекты освещения с меткой генератора. Сохраните копию перед повторным запуском, если правили эти объекты в Studio. Для интеграционных скриптов и пользовательского декора используйте свои папки вне этих двух контейнеров. Генератор меняет глобальные параметры `Lighting`. Если в вашем проекте уже есть `Sky` или `Atmosphere`, проверьте, какой эффект отображается. Генератор выводит предупреждение о таких объектах.

## Настроить размеры и цвета

Создайте `ModuleScript` с именем `LarpTycoonMapConfig` в `ServerStorage` и вставьте содержимое `MapConfig.luau`. В таблице можно оставить только нужные переопределения. Если после правки Studio использует закэшированный результат `require`, замените экземпляр `ModuleScript` новым или переоткройте место, затем запустите генератор.

| Поле | Допустимый диапазон и назначение |
| --- | --- |
| `PlotCount` | Чётное число от 2 до 16. Половина участков на каждой стороне |
| `PlotWidth`, `PlotDepth` | 104–240 стадов. Внутренняя сетка производства сохраняет размеры |
| `PlotGap`, `BorderWidth` | Разрывы между участками 12–48, полоса парка по периметру 20–48 |
| `PlazaDepth`, `RoadWidth`, `SidewalkWidth` | Глубина площади 100–200, ширина дороги 16–32, ширина тротуара 8–16 |
| `Brand`, `PlotColors` | Акценты `#RRGGBB`. `Brand` содержит `Red`, `White`, `Gold`. Цвета используемых участков должны быть различными. Если цветов меньше, чем участков, генератор дополняет палитру |

## Подключить игровую логику

- `Workspace/LarpTycoonMap/Plots/Plot01…` содержит `Site` с фундаментом, `Integration` с площадкой захвата и табличкой, `Sockets` с точками установки и пустую папку `Unlocked` для открытых объектов. `PlotId`, `AccentColor` и начальный `OwnerUserId` находятся в атрибутах модели. Владелец отображается в `Integration/OwnerSign/SignFace/Display/OwnerLabel`.
- `Integration/ClaimPromptPivot` подходит для `ProximityPrompt`. Серверный обработчик должен проверять доступность участка, затем обновлять `OwnerUserId` и текст `OwnerLabel`.
- `ServerStorage/LarpTycoonAssets/FloorShells` содержит `Floor01`–`Floor04`. Первый этаж предназначен для начального производства, второй для улучшенных установок, третий для исследовательского производства, четвёртый для премиальных установок. Верхние этажи включают лестницу с предыдущего этажа. При разблокировке клонируйте нужную модель, вызовите `shell:PivotTo(plot:GetPivot())` и поместите её в `plot.Unlocked`. Открывайте этажи по порядку.
- `Sockets/Floor01/F01_U01` и остальные 63 слота на каждой базе содержат `ItemCFrame` и `ButtonCFrame` в координатах участка. Для установки используйте `plot:GetPivot() * slot:GetAttribute("ItemCFrame")`. Аналогично размещается кнопка, которую создаёт система покупок.
- `UpgradeModels/Floor01/F01_U01` и остальные шаблоны одноимённы слотам. Атрибут `RequiresUpgradeId` связывает производственные модули в цепочку. Координаты `InletCFrame` и `OutletCFrame` заданы относительно модели для маршрутизации по локальной оси `+X`. Детали с `UsePlotAccent` можно перекрасить в `plot:GetAttribute("AccentColor")` при установке.

Цены, обработка покупок, добыча, движение конвейеров, начисления, захват участков и сохранения подключаются отдельными серверными системами. В месте сохранены исходная карта и визуальные шаблоны. Для сохранений используйте идентификаторы улучшений, чтобы прогресс игрока можно было восстановить на любом свободном участке.

## Воспроизвести файл карты в Linux

Потребуются [Lune 0.11.1](https://github.com/lune-org/lune/releases/tag/v0.11.1) и, для отдельной проверки синтаксиса, [Luau CLI 0.748](https://github.com/luau-lang/luau/releases/tag/0.748). Из корня репозитория выполните:

```sh
luau-compile MapGenerator.luau MapConfig.luau tools/BuildPlace.luau > /dev/null
lune run tools/BuildPlace.luau
```

Вторая команда выполнит геометрические проверки и пересоберёт `LarpTycoon.rbxlx`. Добавьте `--check`, чтобы сверить готовый файл с результатом генерации без записи. Для ручной проверки в Studio воспользуйтесь [TESTING.md](TESTING.md).
